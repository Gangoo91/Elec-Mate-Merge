#   1. Search engines            — full public access, app routes closed
#   2. Social preview bots       — open, for OG cards
#   3. AI search + LLM crawlers  — deliberately open; see note below
#   4. Catch-all                 — one group only
#   5. Sitemaps
#
# ⚠️ THERE MUST BE EXACTLY ONE "User-agent: *" GROUP. There were two until
# 2026-08-07 (one listing AI-file Allows, one with the real Disallows). Google
# merges duplicate groups but not every crawler does, and the first group had no
# Disallow at all — so a crawler taking the first match saw an unrestricted site.
# The AI-file Allows are folded into the single catch-all below.
#
# ON AI CRAWLERS: we WANT to be cited. OAI-SearchBot (ChatGPT search),
# Claude-SearchBot, PerplexityBot and Google-Extended are the ones that put us in
# AI answers, so they get the full public site. Training/scraping bots get the
# same public pages but not the app routes.
